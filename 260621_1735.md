## Changed Files

### `track_drive/track_drive.py`

- Changed the active TorchScript default model to `/home/xytron/cone_bc_scripted_2.pt`.
- Increased `control_rate_hz` to `100.0` so 10 ms perception periods can actually run.
- Set stop-line update period to `0.01` seconds.
- Disabled traffic-light-only speed limiting by default while keeping red-light stop logic.
- Set red-light YOLO period to `0.01` seconds and lowered the internal minimum period to 10 ms.
- Tuned stop-line BEV defaults for lower camera view, earlier stop-line detection, and sky filtering.
- Added stop-line reverse behavior when a detected stop line is closer than 3.0 m; release target is 3.6 m.
- Added external speed-limit handling for stop-line, school-zone, person, and optional traffic-light limits.

### `track_drive/stop_line_detector.py`

- Added `source_row_ratio` and original-image row guard to reject sky/high-image false positives.
- Split raw white mask and smoothed white mask so checkerboard-like stop-line false positives can be rejected.
- Added repeat-band guard for multiple separated horizontal white bands.
- Added checker guard for black/white fragmented bands inside a single candidate.
- Added debug reject text such as `repeat guard`, `checker guard`, and `sky guard`.
- Tuned BEV source/ROI, white threshold, row-run, fill, and distance defaults.

### `track_drive/safety_supervisor.py`

- Added new-image-aware stop-line update scheduling.
- Stop-line detection now runs immediately on a new camera frame instead of waiting only for the periodic timer.

### `launch/ai_direct_hybrid.launch.py`

- Changed default model path to `/home/xytron/cone_bc_scripted_2.pt`.
- Added RViz launch support and default RViz config.
- Updated control loop and red-light period defaults to 10 ms behavior.
- Disabled traffic-light speed limiting by default.
- Added stop-line BEV tuning, sky guard, repeat guard, checker guard, and reverse parameters.
- Updated stop-line and intersection approach defaults used by the integrated launch.

### `launch/drive_test_debug.launch.py`
