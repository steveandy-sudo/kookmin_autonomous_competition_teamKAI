## Source Changes

### `cone_il/cone_il/cone_ai_driver_node.py`

- Added `image_qos_depth`.
- Set the default image subscription depth to `1` while keeping RELIABLE QoS, so the cone AI driver favors the newest camera frame instead of processing a delayed queue.

### `launch/ai_direct_hybrid.launch.py`

- Added `camera_qos_depth` launch argument and passed it to both `track_drive` and `switchable_cone_ai_driver`.
- Updated current test-driving defaults:
  - `speed=55.0`
  - `ai_initial_speed=21.0`
  - `school_zone_speed=18.0`
  - school-zone boost disabled
  - straight-only intersection test disabled
  - left-turn execution disabled
  - stop-line stop distance set to `1.00m`
  - stop-line reverse disabled
- Removed the obsolete `yolo_cone_period_sec` launch wiring.

### `track_drive/track_drive.py`

- Added `camera_qos_depth` and set default camera subscription depth to `1` with RELIABLE QoS.
- Updated speed-related defaults for the current test configuration.
- Set stop-line stopping distance to `1.00m`.
- Disabled stop-line reverse by default.
- Disabled school-zone boost by default.
- Removed the obsolete `yolo_cone_period_sec` parameter path.
- Kept left-turn decision latching behavior so a once-confirmed no-cone left-turn wait does not flip back to straight wait just because cones appear later.

### `track_drive/stop_line_detector.py`

- Changed default stop-line stop distance from `5.5m` to `1.0m`.

### `rviz/hybrid_stop_light_debug.rviz`

- Updated RViz window/panel geometry from the latest debug layout state.
