## Package Roles

- `track_drive`: 메인 ROS2 주행 패키지입니다. 카메라, LiDAR, 신호등, 정지선, 교차로 판단을 처리하고 `/xycar_motor` 명령을 발행합니다.
- `cone_il`: 콘 주행용 데이터 수집, 학습, TorchScript 모델 실행 도구를 담은 보조 트리입니다.
- `assets/models`: 팀원이 clone 했을 때 같은 모델 파일을 사용할 수 있도록 런타임 모델을 저장합니다.
- `launch`: 통합 주행 및 디버그 실행 설정을 관리합니다.
- `docs`: 모델 학습/운영 문서를 관리합니다.

## Changes

- 기본 Cone AI 모델을 `cone_bc_scripted_3.pt`에서 `cone_bc_scripted_5.pt`로 변경했습니다.
- `assets/models/cone_bc_scripted_2.pt`와 `assets/models/cone_bc_scripted_5.pt`를 Git 추적 대상에 추가했습니다.
- `.gitignore`에 `_2`, `_5` TorchScript 모델 예외를 추가했습니다.
- `track_drive/package_paths.py`, `launch/ai_direct_hybrid.launch.py`, `launch/drive_test_debug.launch.py`, `cone_il/launch/drive_cone_ai.launch.py`의 기본 모델 경로를 `_5`로 맞췄습니다.
- YOLO 콘 판단 주기를 `yolo_cone_period_sec=0.01`로 별도 설정할 수 있게 했습니다.
- YOLO light/cone 갱신 루프가 신호등 정지 기능만 켜졌을 때가 아니라 교차로 카메라 콘 판단이 켜졌을 때도 동작하도록 조정했습니다.
- 왼쪽 콘 판단을 빠르게 하기 위해 `intersection_left_no_cone_confirm_frames=1`, `intersection_left_cone_memory_sec=0.12`, `intersection_left_decision_delay_sec=0.12`로 조정했습니다.
- `docs/cone_pt_model_training.md`의 기본 모델 예시와 검증 명령을 `_5` 기준으로 업데이트했습니다.
