## Summary

- Changed the default cone AI runtime model from `cone_bc_scripted_4.pt` to `cone_bc_scripted_3.pt`.
- Added the downloaded `_3` TorchScript model under `assets/models/` so it is tracked with the repository.
- Added a training guide for generating cone AI `.pt` models from collected driving data.
- Enabled RViz drive/light debug image displays in `hybrid_stop_light_debug.rviz`.

  - Added the new default TorchScript cone AI model.

- `track_drive/package_paths.py`

- `launch/drive_test_debug.launch.py`
