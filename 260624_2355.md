## Package Hierarchy

```text
kookmin_autonomous_competition_teamKAI/
├── track_drive/                 -> main autonomous driving, perception, safety, and debug nodes
├── cone_il/                     -> cone imitation-learning tools and AI driver source
├── launch/                      -> integrated and debug ROS2 launch files
├── assets/models/               -> runtime TorchScript and ONNX model assets
├── rviz/                        -> RViz debug layouts
├── scripts/                     -> submission/export helper scripts
├── docs/                        -> training and architecture notes
├── package.xml
└── setup.py
```

This repository is the `track_drive` ROS2 package root when cloned under a colcon workspace `src/` directory.

## Source Changes

### `requirements.txt`

- Added a root-level pip requirements file for non-ROS Python dependencies.
- Included packages:
  - `numpy`
  - `opencv-python`
  - `onnxruntime`
  - `torch`
  - `tqdm`
- Excluded ROS2 Humble packages that should come from ROS/apt:
  - `rclpy`
  - `cv_bridge`
  - `sensor_msgs`
  - `std_msgs`
  - `geometry_msgs`
  - `visualization_msgs`
  - `launch`
  - `launch_ros`

## Usage

```bash
cd ~/xycar_ws/src/kookmin_autonomous_competition_teamKAI
python3 -m pip install -r requirements.txt
```

ROS2 Humble should still be installed and sourced separately before building or running the package.
