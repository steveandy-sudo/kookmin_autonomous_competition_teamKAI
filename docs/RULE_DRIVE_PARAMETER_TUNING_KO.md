# 실차 통합 RULE 주행 파라미터 튜닝 가이드

이 문서는 실차 통합 RULE 주행을 시작할 때 입력하는 제어 파라미터의 역할과 조정 결과를 정리한다.

기준 실행 파일:

- xycar_ws/src/xycar_map_nav/scripts/run_complete_space_hybrid.sh
- xycar_ws/src/xycar_rule_drive/xycar_rule_drive/canonical_stanley_pursuit_driver.py
- xycar_ws/src/xycar_map_nav/xycar_map_nav/space_drive_gate_core.py

현재 통합 우선순위는 다음과 같다.

    CONE > YOLO+LiDAR 차량 회피 > RULE

이 문서의 입력 파라미터는 주로 일반 RULE 차선 주행을 조정한다. 콘 구간 진입·종료 조건과 차량 LiDAR 군집 검출 조건은 별도 인지 및 상태전환 파라미터다.

## 1. 실행 방법

    cd /home/xytron/kookmin_ty/integrated_rule_drive_latest/xycar_ws
    set +u
    source /opt/ros/humble/setup.bash
    source install/setup.bash
    export ROS_DOMAIN_ID=7
    unset ROS_NAMESPACE

    bash src/xycar_map_nav/scripts/run_complete_space_hybrid.sh

입력할 때 m, %, cm 같은 단위 문자를 붙이지 않고 숫자만 입력한다. 아무것도 입력하지 않고 Enter를 누르면 기본값이 적용된다.

터미널에 READY가 출력된 후에만 주행을 시작한다.

- Space: 주행 시작
- Space: 다시 누르면 정지
- Ctrl+C: 센서와 제어기 전체 종료

모든 실행값은 다음 파일에 기록된다.

    /tmp/xycar_hybrid_run_config.yaml

## 3. 속도 파라미터

| 파라미터 | 기본값 | 값을 낮추거나 OFF | 값을 높이거나 ON | 지나치게 조정했을 때 |
| --- | ---: | --- | --- | --- |
| 주행 속도 command | 3 | 전체 주행이 느려지고 센서·조향 지연의 영향이 감소한다. | 직선과 곡선 속도가 모두 증가한다. | 곡선 진입이 늦어지거나 인지 전에 콘·차량에 접근할 수 있다. |
| 조향각 기반 속도 가감속 | Y | OFF이면 조향각과 관계없이 입력 속도 상한을 유지한다. | ON이면 조향각이 커질수록 자동 감속한다. | 고속에서 OFF로 사용하면 급곡선 차선 이탈 위험이 커진다. |
| 감속 시작 절대 조향각 | 20도 | 작은 조향에서도 일찍 감속한다. | 더 큰 조향까지 최고속도를 유지한다. | 너무 낮으면 직선에서도 느리고, 너무 높으면 곡선 진입 속도가 높다. |
| 최저속도 도달 절대 조향각 | 42도 | 비교적 작은 조향에서 코너 최저속도에 도달한다. | 급조향까지 속도를 천천히 줄인다. | 너무 높으면 급곡선 감속이 부족하다. 감속 시작각보다 작을 수 없다. |
| 최대 조향 시 속도 command | 8 | 급곡선 통과 속도가 느려진다. | 급곡선 통과 속도가 빨라진다. | 너무 낮으면 곡선에서 멈칫하고, 너무 높으면 차선 이탈 가능성이 커진다. |

실제 최종 출력 속도는 다음 값 중 가장 작은 값이다.

- 입력한 주행 속도 상한
- RULE·콘·회피 선택기가 보낸 후보 속도
- 조향각 기반 속도 제한

따라서 전체 속도가 3이고 최대 조향 시 속도가 8이어도 곡선에서 8로 가속하지 않는다.

### 속도 예시

전체 속도 10, 감속 시작각 20, 최저속도 도달각 42, 코너 속도 6인 경우:

| 절대 조향각 | 적용 속도 |
| ---: | ---: |
| 0~20도 | command 10 |
| 20~42도 | command 10에서 6으로 선형 감속 |
| 42도 이상 | command 6 |

## 4. 곡선 제어 파라미터

| 파라미터 | 기본값 | 값을 낮추면 | 값을 높이면 | 대표적인 부작용 |
| --- | ---: | --- | --- | --- |
| 곡선 Lookahead distance | 0.30m | 가까운 경로를 보고 빠르고 민감하게 조향한다. | 먼 경로를 보고 부드럽고 완만하게 조향한다. | 너무 낮으면 좌우 진동, 너무 높으면 곡선 진입 지연이 발생한다. |
| 곡선 Stanley 비율 | 20% | Pure Pursuit 중심으로 경로를 부드럽게 따라간다. | 차선 횡오차를 더 강하게 보정한다. | 너무 높으면 차선 중심을 쫓으며 오실레이션이 발생한다. |
| Pure Pursuit 제어점 X | -0.08m | 기준점이 뒤로 이동하고 PP 조향이 완만해진다. | 기준점이 앞으로 이동하고 같은 경로에서도 PP 조향이 강해진다. | 너무 높으면 급조향, 너무 낮으면 곡선 반응 지연이 발생한다. |
| Stanley 제어점 X | 0.16m | 차량 가까운 쪽 경로 오차를 사용하여 반응이 늦어진다. | 더 앞쪽 경로 오차를 사용하여 미리 반응한다. | 너무 높으면 먼 차선 노이즈에 민감하고, 너무 낮으면 보정이 늦다. |
| 곡선 Stanley 횡오차 gain | 1.15 | 차선 중심 복귀가 느리고 부드러워진다. | 횡오차에 더 강한 조향 명령을 만든다. | 너무 높으면 좌우 진동과 급조향이 발생한다. |
| 곡선 Stanley 저속 완화값 | 0.35 | 저속에서 Stanley 횡오차 보정이 강해진다. | 저속 Stanley 반응이 완만해진다. | 너무 높으면 곡선 바깥으로 밀리고, 너무 낮으면 저속 오실레이션이 생긴다. |

곡선 Stanley 비율 20%는 Pure Pursuit 80%와 Stanley 20%를 혼합한다는 의미다.

### 곡선 증상별 권장 조정

| 나타나는 현상 | 1순위 조정 | 2순위 조정 |
| --- | --- | --- |
| 곡선 진입이 늦다 | Lookahead 0.30 → 0.27 | PP 제어점 X를 0.02m 증가 |
| 곡선 바깥으로 밀린다 | Stanley gain 1.15 → 1.25 | Stanley 비율 20 → 25 |
| 곡선 안쪽으로 과하게 들어간다 | Stanley gain 감소 | Stanley 비율 감소 |
| 곡선에서 좌우로 흔들린다 | Lookahead 증가 | Stanley gain 감소 또는 softening 증가 |
| 곡선에서 갑자기 크게 꺾는다 | PP 제어점 X 감소 | Stanley 비율 감소 |
| 곡선을 너무 일찍 꺾는다 | Stanley 제어점 X 감소 | Lookahead 증가 |

Pure Pursuit와 Stanley 제어점 X는 영향이 크므로 0.02m 단위로 조정한다.

## 5. 직선 제어 파라미터

| 파라미터 | 기본값 | 값을 낮추면 | 값을 높이면 | 대표적인 부작용 |
| --- | ---: | --- | --- | --- |
| 직선 Stanley 비율 | 90% | Pure Pursuit 비율이 증가하여 진행 경로를 더 우선한다. | 차선 중심 횡오차 보정을 더 우선한다. | 너무 높으면 차선 검출 노이즈를 계속 따라간다. |
| 직선 Stanley gain | 0.65 | 직선 복귀가 느리고 조향이 부드러워진다. | 한쪽으로 밀렸을 때 중앙으로 빠르게 복귀한다. | 너무 높으면 직선에서 좌우 진동이 발생한다. |
| 직선 Stanley softening | 0.65 | 저속에서도 차선 중심을 강하게 보정한다. | 작은 횡오차에 부드럽게 반응한다. | 너무 높으면 차량이 한쪽으로 천천히 밀릴 수 있다. |

직선 Stanley 비율 90%는 Stanley 90%와 Pure Pursuit 10%를 혼합한다는 의미다.

### 직선 증상별 권장 조정

| 나타나는 현상 | 1순위 조정 | 2순위 조정 |
| --- | --- | --- |
| 직선에서 계속 한쪽으로 밀린다 | gain 0.65 → 0.70 | 좌측 주행 보정 확인 |
| 직선에서 좌우로 흔들린다 | gain 0.65 → 0.60 | softening 0.65 → 0.75 |
| 직선 중앙 복귀가 너무 느리다 | Stanley gain 증가 | Stanley 비율 증가 |
| 차선 픽셀 노이즈마다 핸들이 움직인다 | softening 증가 | Stanley 비율 감소 |

## 6. 전환·지연·경로 보정 파라미터

| 파라미터 | 기본값 | 값을 낮추면 | 값을 높이면 | 대표적인 부작용 |
| --- | ---: | --- | --- | --- |
| PP와 Stanley 방향 상충 시 Stanley 비율 | 70% | PP가 요구하는 진행 방향을 더 신뢰한다. | 두 제어기가 반대 방향일 때 Stanley의 차선 중심 복귀를 더 신뢰한다. | 너무 높으면 급격한 역조향이 발생할 수 있다. |
| 제어 지연 예측 시간 | 0.30초 | 현재 경로에 가깝게 계산하여 조향 반응이 늦을 수 있다. | 차량이 이동할 미래 위치를 예측하여 일찍 조향한다. | 너무 높으면 조향이 지나치게 선행하고 오버슈트가 발생한다. |
| 좌측 주행 보정 거리 | 9cm | 목표 경로가 오른쪽으로 이동한다. | 목표 경로가 왼쪽으로 이동한다. | 너무 높으면 왼쪽 경계에 접근하고 우측 회피 공간이 감소한다. |

방향 상충 시 Stanley 비율은 PP와 Stanley가 서로 반대 방향의 조향을 계산할 때만 사용된다. Stanley 반대 조향의 크기가 PP보다 훨씬 큰 경우에는 PP 방향을 보호하는 조건이 적용될 수 있다.

## 9. 안전한 튜닝 절차

1. command 3에서 기본값으로 한 바퀴를 주행한다.
2. 문제가 발생한 구간과 증상을 기록한다.
3. 증상표에서 1순위 파라미터 하나만 변경한다.
4. 동일 구간과 동일 속도로 다시 시험한다.
5. 개선되지 않았을 때만 2순위 파라미터를 변경한다.
6. command 3에서 반복 성공한 뒤 6, 8, 10 순서로 속도를 올린다.
7. 매 시험의 실행 설정과 rosbag을 함께 보관한다.

한 번에 여러 값을 변경하면 어떤 값이 문제를 개선하거나 악화했는지 판단하기 어렵다.

## 10. 이 입력값으로 직접 해결되지 않는 문제

다음 문제는 이 문서의 17개 입력값이 아니라 별도 콘·차량회피 파라미터와 상태전환 코드를 조정해야 한다.

- 콘 구간 진입이 늦음
- 콘 구간이 끝나기 전에 RULE 또는 RL로 복귀
- 차량 YOLO 감지 후 LiDAR 군집을 연결하지 못함
- 회피 방향을 결정하지 못하고 WAIT_SIDE_CLEAR에서 정지
- 카메라 차량 영역과 LiDAR 군집의 거리·각도 연관 실패
