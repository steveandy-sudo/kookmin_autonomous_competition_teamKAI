# 2026-08-19 KTY 첫 수정

## 오늘 수정한 내용

1. 신호등 판단
   - `red_4`, `yellow_4`, `green_4`의 bbox 크기를 거리 조건으로 사용하지 않도록 변경했습니다.
   - confidence와 기존 2프레임 확인 조건은 유지했습니다.

2. 차량 및 장애물 회피
   - 직선뿐 아니라 곡선에서도 최신 노란 중앙선을 기준으로 장애물의 좌우 위치를 판단하도록 변경했습니다.
   - 장애물이 차량 오른쪽에 있으면 왼쪽으로, 왼쪽에 있으면 오른쪽으로 회피합니다.

3. 라바콘 주행 복귀
   - YOLO와 LiDAR에서 콘이 모두 사라진 뒤 센서 유효시간 `0.5초`가 지나면 RULE 주행으로 복귀하도록 변경했습니다.
   - 기존의 추가 복귀 대기시간 `1.0초`는 제거했습니다.
