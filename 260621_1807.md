## Package Hierarchy

```text
xycar_ws/
├── ROS-TCP-Endpoint-main-ros2/       # workspace-level Unity ROS bridge package
└── src/                              # git repository root
    ├── assets/
    │   └── models/
    │       ├── cone_bc_scripted_4.pt  # default cone AI TorchScript model
    │       └── final.onnx            # default YOLO ONNX model
    ├── track_drive/                  # main autonomous driving node package code
    ├── launch/                       # integrated and debug ROS2 launch files
    ├── rviz/                         # RViz debug layouts
    ├── cone_il/                      # cone imitation-learning tools and launch files
    ├── docs/                         # architecture/planning notes
    ├── scripts/                      # helper scripts
    ├── package.xml
    ├── setup.py
    └── README.md
```

`colcon list` discovers `track_drive` from this repository root. The nested `cone_il/` tree is kept as supporting code and launch/tooling in this repository layout.

## Runtime Asset Layout

- Added `assets/models/cone_bc_scripted_4.pt` so the default cone AI model is tracked by git.
- Added `assets/models/final.onnx` so the default YOLO traffic-light/person model is tracked by git.
- Updated `setup.py` so `colcon build --symlink-install --packages-select track_drive` installs these models under `share/track_drive/assets/models/`.

## Source Changes

- `.gitignore`: kept general large model ignores, but explicitly allowed the two required runtime models under `assets/models/`.
- `setup.py`: added model assets to package data installation.
- `package.xml`: added `ament_index_python` runtime dependency for package share path lookup.
- `track_drive/package_paths.py`: added shared helpers for resolving packaged model paths with a source-tree fallback.
- `track_drive/track_drive.py`: changed default AI/YOLO model parameters from `/home/xytron/...` absolute paths to packaged model paths; allowed ONNX Runtime CPU fallback in `auto` mode.
- `track_drive/traffic_light_detector.py`: changed default YOLO model path to the packaged model and added ONNX Runtime inference before OpenCV DNN fallback.
- `track_drive/intersection_debug_node.py`: changed debug YOLO default path to the packaged model.
- `launch/ai_direct_hybrid.launch.py`: changed cone and YOLO model defaults to `FindPackageShare('track_drive')/assets/models/...`.
- `launch/drive_test_debug.launch.py`: changed cone model default to the packaged model.
- `launch/traffic_light_debug.launch.py`, `launch/intersection_debug.launch.py`, `launch/light_debug.launch.py`: changed YOLO model defaults to the packaged model.
- `cone_il/launch/drive_cone_ai.launch.py`: changed standalone cone AI launch default to the packaged cone model.
- `README.md`, `cone_il/README.md`: documented the new runtime model layout and ONNX Runtime requirement.
